# Video Extractor 배포 파일

이 저장소는 [Video Extractor](https://github.com/Sunya0804/video-extractor) 설치 파일과 자동 업데이트용 파일만 올리는 곳입니다.

**[최신 버전 받기 (Releases)](https://github.com/Sunya0804/video-extractor-releases/releases/latest)**

| 대상 | 받을 파일 |
|---|---|
| Windows PC | `VideoExtractor-Setup-<버전>.exe` |
| 안드로이드 | `VideoExtractor-<버전>.apk` |

설치한 앱은 이 저장소의 새 릴리스를 확인해 자동으로 업데이트합니다.
